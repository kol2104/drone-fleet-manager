# Drone Fleet Manager

Drone Fleet Manager — серверная система для управления парком дронов. Она помогает вести реестр устройств, запускать полётные миссии и отслеживать их выполнение.

Оркестрация миссий построена на Camunda. RabbitMQ передаёт команды и результаты полёта, PostgreSQL хранит состояние устройств, а Elasticsearch и Kibana позволяют искать историю операций.

## Возможности

- Регистрация дронов и просмотр их состояния и доступности.
- Запуск миссии с маршрутом и выбранным устройством.
- Проверка условий и резервирование дрона перед запуском.
- Отправка команды на полёт и ожидание результата или истечения времени ожидания.
- Обработка успешного и неуспешного завершения, освобождение устройства и запись результата.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| **Управление миссиями** | Принимает заявки, запускает процесс полёта, отправляет команду устройству и обрабатывает результат. |
| **Camunda 8** | Координирует шаги миссии: проверки, резервирование, ожидание ответа и обработку тайм-аута. Ход процесса можно посмотреть в Camunda Operate. |
| **Реестр дронов** | Хранит сведения об устройствах, их статусе и резервировании. PostgreSQL служит основным хранилищем этих данных. |
| **RabbitMQ** | Передаёт команды полёта и ответы устройств. |
| **Elasticsearch и Kibana** | Elasticsearch хранит журнал событий; Kibana позволяет искать и просматривать его. |

## Как проходит миссия

Клиент отправляет миссию в Mission Control. Camunda проверяет запрос и погодные условия, затем Mission Control резервирует выбранный дрон в Device Registry. Если проверки или резервирование не пройдены, команда не отправляется, а причина отказа сохраняется. При успешном резервировании команда с маршрутом и идентификаторами миссии и дрона публикуется в RabbitMQ. Адаптер устройства должен получить её и отправить результат полёта обратно в RabbitMQ; Mission Control передаёт результат в Camunda, которая запускает освобождение резерва в Device Registry и запись итога миссии в Elasticsearch. Автоматического адаптера нет (ожидание сообщения от дрона или внешнего сервиса): без сообщения с результатом миссия ждёт до 15 минут, затем завершается по тайм-ауту, а резервирование освобождается.
